# **📕Book Management System (BMS)**
这是一个基于 SQL Server 2022 和 Visual Studio 2022 完成的图书馆管理系统。
## 📋系统功能设计  
本图书馆管理系统能实现以下功能：  
 
| 功能 | 说明 |
|:-----|:-----|
| 登录功能 | 分为系统管理用户登录和读者登录，系统用户登录后显示系统管理主界面，读者用户登录后显示读者借阅主界面； |
| 系统管理主界面 | 该主界面显示的菜单项有：图书类别管理、图书管理读者类别管理、读者管理；|
| 读者借阅主界面 | 该主界面显示的菜单项有：图书借阅管理,图书类别管理功能 ,图书管理功能,读者类别管理功能,读者管理功能,图书借阅管理功能. |



- 管理界面中用列表显示数据；列表中的类别数据项需要显示名称；
 
- 管理功能中：**增、删、改、查**要完备；
- 增加和修改功能中的类别数据需要从下拉列表中选取，下拉列表中的数据为对应数据表中的类别数据；  

 通过上述功能，可实现：
 - 实时查询书库书籍种类、数量及位置，书籍通过唯一书号识别；
 - 查询书籍借还详情，包括借阅者信息及借阅日期；支持一书多借，借书证号唯一。  

 系统用户分为**管理人员**和**普通用户**：  
- 管理人员负责图书信息的增删改查、普通读者信息的增删改查、数据库管理，同时可以修改个人密码与普通读者密码（防止读者因忘记密码而无法登录）；  
- 普通用户可查询书籍信息、借阅归还图书、查看个人借阅及修改密码。
